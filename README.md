# news-digest · 中文科技新闻推文生产与展示

一个围绕「AIHOT 每日科技新闻」的自动化内容管线：定时抓取新闻、按两套写法转成推特长文、写入数据文件、由网页实时读取并分栏展示。仓库同时归档旷野体的写作规范与风格校验脚本。

## 目录结构

```
.
├── news-digest/                 # 主线：新闻推文项目
│   ├── 记录.html                # 前端页面，两栏展示（A 栏 v1 速览 / B 栏 v2 热点）
│   ├── posts.jsonl              # 推文数据源，每行一条 JSON
│   ├── app/server.py            # Flask 服务：页面、数据、判重、写入
│   ├── site/                    # 软链目录，供静态托管
│   ├── drafts/                  # 草稿
│   ├── 发布台账.md              # 人工维护的发布记录
│   └── 2026-11-16_21时_*.md     # 早期人工产出留档
├── kuangye-writing/             # 旷野体写作技能包 + 本地要求文件
│   ├── SKILL.md                 # 技能主文件
│   ├── 写作要求.md              # 本地硬规则 W01–W10 + 人味手法 R01–R12
│   ├── 格式对照.md              # A 栏 / B 栏的句式与篇幅对照
│   ├── 意见记录.md              # 逐条积累的修改意见台账
│   ├── 写作范式/                # 钩子开路 / 提问引流 / 借壳反转
│   ├── 要求与体裁/              # 人味写作、安利体、样本库 v2
│   └── scripts/check_style.py   # 风格校验脚本

└── X中文区观察分析_整理版.md
```

## 数据结构

`news-digest/posts.jsonl` 每行一条，字段固定：

| 字段 | 说明 |
| --- | --- |
| `round` | 场次标识，如 `2026-11-18 20时` |
| `title` | 标题，判重依据 |
| `st` | 状态，`new` 全新 / `overlap` 有重叠 / `same` 同一事件新进展 |
| `note` | 一句话定性，说明为什么值得看 |
| `text` | 正文，段落之间空行分隔 |
| `src` | 栏目，`v1` 新闻速览 / `v2` 热点解构 |

`src=v1` 取自速览写法，中位 269 字、4 段；`src=v2` 取热点解构写法，中位 84 字、2–4 个短块、首行 4–16 字。

## 服务端接口

`app/server.py` 默认监听 3000 端口，可用环境变量 `PORT` 覆盖。

| 路由 | 方法 | 用途 |
| --- | --- | --- |
| `/` | GET | 返回 `记录.html` |
| `/posts.jsonl` | GET | 返回全量数据 |
| `/list` | GET | 判重用的精简清单，含序号、场次、标题、状态、前 160 字摘要 |
| `/count` | GET | 总条数 |
| `/append` | POST | 追加数据，需 `X-Sync-Token` 请求头；默认按标题判重，`?force=1` 强制写入 |

判重逻辑：去掉标点与数字后，公共前缀达 8 字，或汉字 bigram Jaccard 相似度 ≥ 0.55，即判为同一事件。

令牌存放在 `news-digest/.sync_token`，已被 `.gitignore` 排除，不入库。

## 写作规范

本地要求文件集中在 `kuangye-writing/`，规则优先级高于技能包自带说明：

- 句子长度必须有抖动，不允许整段同一节奏
- 开头直进事实，不写"最近有个新闻"这类铺垫
- 段与段之间空行，一条推文禁止整段糊成一坨
- 禁用引号书名号符号化的强调、禁用 emoji、禁用免责式收尾
- 同一事件再次出现时，必须有新事实才写，否则跳过

新增意见只写入 `意见记录.md`，不修改技能包本身，保证技能包与发行版一致。

## 版本管理约定

每次会话产生改动后，按以下顺序收尾：

1. `git add -A`（`.gitignore` 已排除令牌、缓存、会话数据）
2. 提交信息写清改了什么，例如 `新增 20时场次 6 条推文`
3. `git push origin main`

一键操作：

```bash
./sync.sh "提交说明"
```

未传说明时，脚本按当前时间自动生成。

## 线上页面

两栏页面通过 `posts.jsonl?sharecode=...&v=时间戳` 拉取数据，`v` 参数用于绕过缓存。
