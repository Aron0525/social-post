## 这个文件干什么

三栏不是三种长度，是三种职能：

| | 比什么 | 靠什么赢 | 读者拿到什么 |
| --- | --- | --- | --- |
| A 新闻 | 完整度 | 事实、数字、机制，讲透 | 能拿去复述、能当资料 |
| B 热点 | 速度 | 比别人早，角度比别人刁 | 一个判断 |
| C 博眼球 | 停留 | 结构，前三个字能不能钩住 | 一个印象 |

**网站和定时任务都按这三栏跑**：新闻速览 v1、热点解构 v2、博眼球 v3。判重按栏目各算各的，同一件事可以在三类里各写一条。

## A 栏 · 现行格式 v1

### A1 实测结构参数（基于网站 94 条成稿统计）

| 指标 | 实测值 | 备注 |
| --- | --- | --- |
| 总字数中位 | 269 字 | 最短 58，最长 553，跨度很大 |
| 段数中位 | 4 段 | 最常见 4 段，范围 1 到 9 |
| 每段句数 | 1 到 3 句 | 长短不对称，不强制齐整 |
| 总句数中位 | 6 句 | 范围 2 到 15 |
| 单句字数中位 | 29 字 | 10 字以内占 9%，30 字以上占 49% |
| 首句字数中位 | 27 字 | 43% 的首句带数字 |
| 末句字数中位 | 28 字 | 31% 的末句带数字，多数停在事实 |

### A2 结构模板

```text
第一段  一个短判断或直接甩事实，一两句，不带铺垫
第二段  事实主体，公司名、日期、具体数字
第三段  细节或反常识点，一到两句
第四段  停在数字、日期或动作上，不总结
```

### A3 要素清单

| 要素 | 现行做法 |
| --- | --- |
| 开头 | 直接进事实，禁止最近、随着、众所周知 |
| 句长 | 必须抖，一条里至少一句 10 字内、一句 30 字以上 |
| 段落 | 段间空一行，一段一个意思，超 100 字必拆 |
| 口吻 | 第一人称只用于视角（我看、我翻了一遍），不交代核实过程 |
| 免责 | 一律不留，核不实就整句删掉 |
| 结尾 | 停在事实或动作，不升华、不提问、不喊关注 |
| 标点 | 无引号、无感叹号、无破折号省略号、不加粗、无 emoji |
| 长度 | 分三档，见 A6 | 短帖、常规、深度稿各有各的用法 |
| 三段标注 | 每条标全新、部分重叠、与之前一模一样，配一句说明 |

### A4 代表样例

```text
Anthropic 要上市了。70 到 78 美元一股，代码 ANT，19 号上纳斯达克。

招股书里写的是前九个月收入 332.4 亿美元。认购倍数外面在传 6 倍，公司自己没提。

以前这些 AI 公司想讲多大故事都行，没人能拿财报打脸。上市之后不行了，一个季度交一次表，讲错了要担责。

19 号挂牌。那天离财报季也不远。
```

### A5 A 栏的已知问题

这份清单是从实际成稿里看出来的短板，也是这次优化的靶子：

1. 中位 269 字，对 X 的阅读节奏偏长，前两句很容易被划走
2. 首句 27 字、末句 28 字，两端偏长，缺少一击命中的短句
3. 结构固定成四段，段段都是完整句，读起来像简报，不像帖子
4. 43% 首句带数字，信息密度够，但缺情绪钩子和视线抓手
5. 通篇没有分行短句堆叠，也没有单句成段的节奏变化

### A6 三档长度

新闻栏的任务是把事讲完整、把机制讲明白，长度不该被 350 字卡住。按素材量分三档，写完对一下档位，不要为了凑字数灌水，也不要为了短砍掉机制。

| 档位 | 字数 | 什么时候用 | 必须写到的 |
| --- | --- | --- | --- |
| 快讯 | 80 到 200 | 单一事实，一句话能说完 | 谁、做了什么、数字 |
| 常规 | 250 到 450 | 有背景、有对比、有一个反常识点 | 加：为什么、和之前比变了什么 |
| 深度 | 500 到 900 | 财报、监管、技术路线、产业链变化 | 加：机制怎么运转、谁受损谁受益、下一步看什么 |

深度稿的结构（不是四段，是五块）：

```text
1 结论先行    一到两句，把最重要的事实或判断放最前面，不铺垫
2 事实主体    数字、时间、主体、动作，密度最高的一块
3 机制拆解    这件事为什么发生，钱怎么流，谁被逼着做了什么
4 反面或代价  有人赚就有人亏，反常识点放这里，别放在开头泄掉悬念
5 观察点      下一步看什么，给一个可验证的信号，不预测结果
```

第 3 块是深度稿和常规稿的分水岭。写完自检一句：**把第 3 块删掉，这篇还成立吗？** 成立说明机制没写进去，只是把常规稿拉长了。

深度稿允许用数字列表（营收、增速、指引逐条列），但列表前后必须有解释性段落，不能整篇都是条目。

## B 栏 · 新格式 v2（已定，依据 S01 至 S07）

详细版在 `写作范式/` 目录，样本原文在 `要求与体裁/样本库-v2.md`。这里只放结论。

### B1 实测参数表

| 指标 | v1 实测 | v2 目标 | 差距 |
| --- | --- | --- | --- |
| 净字数 | 中位 269 | 中位 98，范围 29 到 244 | 砍掉约三分之二 |
| 块数 | 中位 4 段 | 2 到 5 块，最常见 4 | 基本持平 |
| 首行字数 | 中位 27 | 2 到 16，中位 11 | 砍一半以上 |
| 首行收尾 | 句号 | 逗号或冒号，句号禁用 | 换停顿符 |
| 首行性质 | 事实陈述 | 钩子，带信息缺口 | 从报告改叫卖 |
| 全篇陈述句 | 5 到 6 句 | 不超过 3 句 | 减半 |
| 感叹号问号 | 禁用 | 允许，鼓励？和？！ | 放开 |
| 编号清单 | 几乎不用 | 3 条递进，可用 | 新增 |
| 收口 | 停在数字 | 损失、情绪、追问、行动四选一 | 多三种出口 |

### B2 结构模板

```text
钩子行    2 到 16 字，逗号或冒号收，独立成行
          ↓ 空一行
主体      2 到 3 块，每块一个意思，兑现钩子的信息缺口
          ↓
收口      一句短句，落在损失、情绪、追问或动作上
```

钩子九型：冷知识、暴论、真理、建议、白嫖、扎心提问、人群分类、示弱求教、名人引用。
主体六型：比例换算、编号清单、对照追问、断言加动作串、数据点堆叠、算账。
收口五型：损失换算、情绪爆破、复问不收口、断言加行动、定性断言。

三种范式分工：

| 范式 | 什么时候用 | 依据 | 一句话 |
| --- | --- | --- | --- |
| 01 钩子开路 | 默认，有明确结论的新闻 | S01 至 S04 | 钩子开场，正文兑现 |
| 02 提问引流 | 数据反常、现象矛盾、行业困惑 | S03、S05、S07 | 全篇不给答案，答案在评论区 |
| 03 借壳反转 | 有认知差、有现成观点可引 | S06 | 前四块借别人的嘴，最后一块自己定性 |

### B3 代表样例

```text
冷知识，

Codex Pro 200 每消耗 1% 的额度，就相当于 Plus 消耗 20%，

相当于Pro 用户随手烧掉 5%，Plus 用户的一整份周额度就没了。
```

```text

```

### B5 热点监测机制

热点栏不能靠"想起来今天有什么新闻"，得有一份实时的榜。已经做成接口挂在本机服务上：

```bash
curl -s "http://127.0.0.1:3000/hot?topic=tech&limit=30"
```

**五个源并行抓取**，任一源超时不拖累其他：

| 源 | 抓什么 | 特点 |
| --- | --- | --- |
| 微博热搜 | 全网最大众的情绪出口 | 带热度值，娱乐占比高 |
| 抖音热榜 | 短视频侧的注意力 | 热度值最直观 |
| 知乎热榜 | 中长文讨论，问题形式 | 适合找"提问引流"的题 |
| 百度热榜 | 搜索侧的真实关心 | 不带热度，按名次折算 |
| 华尔街见闻快讯 | 财经第一落点 | 带时间戳，最快，适合抢 1 小时 |

**跨榜聚类**是这套机制的核心。同一条内容出现在四个榜，说明它真的在爆；只在一个榜出现，可能只是那个平台的口味。返回结果里 `cross` 就是命中榜数，排序先看 cross 再看热度。实测今天 `GTA6` 四榜全中，`史上最大IPO ANT 1.5万亿`、`孙正义后悔没投 Anthropic` 各两榜。

**题材过滤**按账号定位执行：政治、外交、领导人行程、军事在抓取阶段就打 `risk=politics` 剔除，不进入候选池。实测 227 条原始数据剔掉 52 条。`?topic=tech` 只留科技、财经、产业相关，今天剩 19 条。

**怎么用这 19 条**：

1. `cross` 越多的越是真热点，优先写
2. 单个榜但排名靠前的，看是不是那个平台特有的情绪（知乎的提问、微博的争议）
3. 华尔街见闻那条带时间的，是 1 小时内能抢的，先写这条
4. 榜单只给"发生了什么"，判断还得自己给。榜上写"孙正义后悔没投 Anthropic"，v2 要回答的是"他为什么现在说这话"

缓存 5 分钟，定时任务每轮调一次就够，不需要自己维护榜单。

## C 栏 · 博眼球格式 v3

C 栏不问"讲清楚了没有"，只问"第一句能不能拦住划动的手"。前面两栏靠信息，这一栏靠结构。

**C 栏和新闻解绑。** 不要求当天有事发生，也不要求是新闻。给一个数字、一个反常识判断、一句吐槽，套上结构就能成篇。素材来源可以是当天热点，也可以是三天前的旧事、一个行业常识、你自己踩的坑——读者看的是结构带来的爽感，不是信息增量。

完整骨架库在 `结构库-v3.md`，共 12 个可套用模板，每个带填空位和例句。这里只放三条基准。

### C1 参数

| 指标 | v3 目标 | 说明 |
| --- | --- | --- |
| 字数 | 60 到 130，上限 150 | 比 v2 略长，比 v1 短一半 |
| 块数 | 3 到 5 块 | 一句一块，段间空行 |
| 首句 | 数字或反常识断言，10 到 20 字 | 不留铺垫 |
| 数字 | 至少一个，必须真 | 假数字是最快的翻车方式 |
| 转折 | 全篇至少一次 | 没有转折就只是通报 |
| 结尾 | 反转、悬念或一句判断 | 不解释，不总结，不喊关注 |
| 语气 | 可以带情绪 | 不用脏话，不用 emoji，不用感叹号连击 |
| 禁止 | 假引述、承诺收益、煽动对立、编造细节 | 结构可以夸张，事实一条都不能假 |
| 素材 | 不限于新闻，纯结构也行 | 但出现的每个数字、公司、时间必须真实 |

### C2 三条基准结构

**1 数字对撞**：一个刺眼数字开场，事实推进，最后把两件矛盾的事放在同一句里。

```text
1158 亿美元。

一个季度，营收翻倍，数据中心 1076 亿，下季度还要 1300 亿。

然后董事会说，不请老黄回来。
```

**2 反常识断言**：先给一句和直觉相反的判断，中间补机制，结尾落回一个具体事实。

```text
今天银行又涨了。

不是因为看好，是因为不能只卖不买。

指数弱的时候，单边砸盘会被打电话。想卖科技，就得顺手买点银行，账面上才配得上。

所以银行涨得越欢，说明科技被清得越急。
```

**3 悬念收尾**：数字三连堆出规模感，最后一句只陈述状态，把疑问留给读者。

```text
一家还没上市的公司，账上 1319 亿美元现金。

烧了三年钱，累计 100 亿，今年 9 月现金流转正，净流入 65.7 亿。

5300 人，人均年产 1200 万美元。

就这么一家公司，正在准备上市。
```

### C3 三栏分工

| | v1 新闻速览 | v2 热点解构 | v3 博眼球 |
| --- | --- | --- | --- |
| 职能 | 把事讲全，能做报告 | 抢时间，追当天热度 | 抢注意力，制造停顿 |
| 选题来源 | 行业新闻、财报、监管、技术发布 | `/hot` 监测榜单，跨榜优先 | 不限，结构本身即选题 |
| 时效 | 48 小时内 | 当天，最好 1 小时内 | 不限 |
| 字数 | 80 到 900，分三档 | 30 到 250 | 60 到 150 |
| 第一句 | 事实 | 钩子 | 数字或反常识断言 |
| 读者拿走什么 | 细节和机制 | 一个判断 | 一个印象 |
| 必须有什么 | 至少一个可核对的数字 | 至少一处"别人没说的角度" | 至少一次转折 |
| 失败的样子 | 像简报 | 像通稿 | 像标题党，点开没货 |

三栏互不依赖：
- v1 写完，v2 可以就同一件事给判断，v3 可以就同一件事抽一个数字做钩子
- v3 也可以完全不看 v1 v2，直接从结构库里挑一个套上去
- 判重按栏目分开，v1 写过不影响 v2 v3

C 栏最容易滑向标题党，判断标准只有一条：**读完最后一句，读者有没有拿到至少一个新事实。** 没有，就是空转，退回重写。

## 数据集接收方式

三种给法，任选：

1. 直接贴在对话里。一条帖子一段，中间用空行或 `---` 隔开，我按顺序编号
2. 存成 txt 或 md 放到 `/root/uploads`，告诉我文件名
3. 给 GitHub 仓库地址或网页链接，我自己抓

收到后我会做四件事，都在 B 栏里留痕：

1. 建样本库 `要求与体裁/样本库-v2.md`，原文照录，带编号，不改一个字
2. 跑统计，得出 B1 那张参数表
3. 归纳两到三个结构骨架，写进 B2
4. 拿三条现有 AI 新闻重写成 v2，与 A 栏版本并排放，你自己判断哪个像帖子

## 到底怎么算两栏

有两种可能，你确认一下是哪种：

- 版本对照：两栏是两套并行标准，平时只用一套，需要时切换。定时任务继续用 A，手动要新格式时用 B。
- 双版本输出：同一条新闻同时给 A 版和 B 版，你自己挑发哪条。

我按第一种先搭，因为你说要保留现有处理方式。如果是第二种，说一声，我把输出改成一条新闻两版并排。
