# 范式 03 · 借壳反转

> 日期：2026-11-18
> 依据：S06 陈丹青引用
> 状态：生效，与范式 01、02 并列
> 一句话：**前四块都是别人的话，你只在最后一块下判断。**

## 一、结构图

```text
第 1 块   引用引入，XX 说过这么一段话：/ XX 有个说法：
          ↓ 空行
第 2 块   被引用者的预期，他们以为事情是 A
          ↓ 空行
第 3 块   现实打脸，结果发现是 B，跟他想的正好相反
          ↓ 空行
第 4 块   归因，其实是他们不懂 X
          ↓ 空行
第 5 块   定性断言，一句话判死，带感叹号
```

五块缺一块就散。缺第 4 块，反转变成抱怨；缺第 5 块，全文没有落点。

## 二、为什么要借壳

| 好处 | 说明 |
| --- | --- |
| 责任转移 | 判断是名人说的，作者只负责复述和补最后一刀，被反驳时退路干净 |
| 开场成本低 | 不用自己想钩子，引用本身就是钩子 |
| 反转有落差 | 预期和现实摆在一起，读者自己会算出荒谬感 |
| 评论区有话说 | 反转针对的是认知差，读者要么认同要么举反例，两种都会留言 |

## 三、写法要点

### 第 1 块 引用引入

- 五个模板：XX 说过这么一段话：/ XX 有个说法：/ 看到一个观点：/ 有人问过 XX，/ XX 讲过一件事：
- 必须真有其人其言，查不到的不能编。编了就改成 看到一个说法，
- 不写头衔、不写年份、不写书名的第几页，越短越像转述

### 第 2 块 预期

- 要写得让读者也信。写不服人，后面反转就没有落差
- 用冒号接一串并列，四到六个词，每个词两到四字：脑子好、有道德、有文化
- 这一块可以最长，S06 这里是 66 字

### 第 3 块 打脸

- 开头用 结果 或 后来，明确转折
- 打脸要具体到行为，不写 大跌眼镜 这种空话
- 这一块也要一串并列，跟第 2 块形成镜像

### 第 4 块 归因

- 固定句式：其实是 X 不懂 Y
- 归因要一句说完，不展开论证
- 这一块是全篇的判断核心

### 第 5 块 定性

- 一句话，带感叹号，20 字以内
- 用 根本 恰恰 这种绝对词加强，但只在这一句用

## 四、硬参数

| 项 | 值 |
| --- | --- |
| 净字数 | 180 到 250 |
| 块数 | 5，不能少 |
| 首行 | 8 到 14 字，冒号收 |
| 并列串 | 至少两处，一处在第 2 块，一处在第 3 块，每处 4 到 6 项 |
| 感叹号 | 1 个，只在最后一句 |
| 问号 | 可以用反问，不超过 2 个 |

## 五、符号处理（重要）

S06 原样本用了破折号、弯引号、感叹号各一处。结构可以借，符号不借：

| 样本用法 | 我们的写法 |
| --- | --- |
| 还带着贵族精神——不然，凭什么能发财呢 | 还带着贵族精神。不然凭什么能发财 |
| 另一套“基本素质” | 另一套基本素质 |
| 你根本不可能成为有钱人！ | 保留感叹号，这是本范式唯一允许的 |

## 六、风险边界

这个结构天生适合争议话题，也天生容易踩线。三条红线：

1. 不针对真实存在的群体做贬损。S06 涉及地域和人群的刻板印象，这类题材不生成，哪怕样本数据很好
2. 引用必须真实。名人名言错挂是硬伤，查不到就换成 看到一个说法
3. 归因不能指向民族、性别、职业、地域。要归因就归因到制度、认知、利益结构

想用这个结构又不想踩线，把对象换成行业、公司、某种做法。批判一个行业比批判一群人安全，反差也不小。

## 七、自检

1. 引用是真有其人其言吗？查不到就改成 看到一个说法
2. 第 2 块写得让人信吗？读者会不会觉得一开始就是傻的
3. 第 3 块和第 2 块是不是镜像的并列串
4. 第 4 块的归因有没有指向人群
5. 最后一句有没有超过 20 字
6. 全篇有没有第二个感叹号，有就删
