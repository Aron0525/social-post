- **发布痕迹不学**：原书错字病句（p0548「要协」、p0103「先做着」、p0663「成为是牛马」、p1378「源白」、p1898「无法拥明天」）属发布痕迹，引用照录、不修正、不学其字词。
- **规范冲突**：`BOOK_OVERVIEW` 已注明 Aron 现行 `human-writing` 硬规则禁冒号、破折号、翻案腔（「不是……而是……」）、商业黑话、洞察路标词（含「说到底」）。本维度大量手法正好踩线——编号清单用冒号与数字编号、本质推进用「说到底 / 其实」、反常识用「并不是 X，而是 Y」，而全书含冒号 666 帖 / 16.4%、含不是而是 397 / 9.8%、广义不 X 是 Y 659 / 16.3%。本文件把这些**登记为可识别、可选择**：默认遵守现行规范，仅当明确要求复刻原帖风格、且显式开启开关时使用，**绝不静默覆盖既有规范**。
- **只归纳可迁移的写法**：不含「模仿作者人设」「扮演作者」「复刻冷感语气」一类内容。语气、词汇、句子骨架归 02 / 03 / 01 维度。
- **与 01 文件的分工**：01「结构与起收」讲一条帖子几句、怎么起怎么收（其 02 断言领起+补充、05 设问自答、07 编号清单、08 先场景后判断是**骨架视角**）；本文件讲**信息排序与证据组织**——同一批帖子改从「结论/证据/现象谁先谁后、证据怎么摆、因果怎么走、项按什么维度排」切入，不重复 01 的起收分类。

## 01 · 断言先行（先给结论再补证据）

- **type**：信息顺序 / 结论前置
- **一句话概括**：首句直接钉死判断，后文只做「补证」——细化对象、给一句依据或第二人称担保，证据服从结论，不重新论证、不另起总结段。
- **原文引用**：
```
喜欢开口借钱的人，人品往往都有问题。尤其是已成年，却还向朋友、亲戚、家人借钱的，而且借的还都是几百几千这种小钱。你放心，指望这种人还钱，是不可能的。他们习惯了靠别人，而且根本不想着靠自己去改变现状。
```
- **出处**：
  - p0627 ｜ 2025/11/12 ｜ 第 66 页（101 字，完整帖；结论「人品往往都有问题」→「尤其是」细化 →「你放心」担保 → 补一层理由）
  - p0103 ｜ 2026/02/24 ｜ 第 13 页（89 字，完整帖；「人一定是靠冷漠去赢得尊重的」领起，原文含错字「先做着」，照录不学）
  - p0418 ｜ 2025/11/25 ｜ 第 44 页（37 字，完整帖）
  - p1766 ｜ 2025/09/08 ｜ 第 184 页（34 字，完整帖）
- **频次 / 量化依据**：Grep `corpus.md` `因为` **919 行** / `posts.jsonl` **810 帖（20.0%）**、`所以` **453 行 / 430 帖**；`stats.md`「每帖句数中位 3」「三句以内 2144 / 52.9%」—— 2–3 句正是「结论＋补证」的容器。与 `BOOK_OVERVIEW` 写法骨架第 1、3 步（「直接抛结论，不交代背景」「需要说服力时补一组硬数字、具体人名或按年龄分层的生活场景」）对应。断言先行无单一字符串可精确计数，此处以「补充标记命中数 + 句数中位」佐证。
- **可执行的动作**：模板 `【判断句（无「可能/也许/我认为」）】。【尤其是/因为/你放心 + 一层补证】。【可选：收在判断，不另开话题】`。写短帖先问「这个判断能不能一句话说死」；能，就先输出它，再只补**一层**证据。校验：首句若含情态词或背景铺垫，即偏离此顺序；补证超过两层即滑向论证长文。
- **边界与失效场景**：适用于读者已默认接受的常识型判断、强观点帖；**结论反直觉、需要说服、涉及免责或需列多方观点时改用候选 03 的现象前置**。迁移到需要论证的长文会变成 `BOOK_OVERVIEW` 指出的「一堆无法支撑的结论」；安慰、讣告、致谢、客服、科普不宜冷断言领起。原书数字与错字不学。

## 02 · 先摆现象再下判断

- **type**：信息顺序 / 现象前置（与 01 反向）
- **一句话概括**：先把一个可观察的现象、场景或案例摆够，末句才落判断；现象在前，判断在后，中间不提前剧透结论。
- **原文引用**：
```
你喜欢别人的老婆，这样说，是不是显得你很坏？你喜欢的人，做了别人的老婆，这样是不是好一点？语言即世界。
```
```
1937 年12 月的南京，仅有少量的日本兵押解着2000 名被俘虏的南京警察到汉中门外集体处决。俘虏们冷漠地向前走着，每个人都在等别人先动手，这样自己才能活下来。先动手的人可想而知必死无疑，所以没有人愿意用自己的死换别人的生，结果是全部被杀。这种精到骨子里的自私，至今仍然是很多人的心态。
```
- **出处**：

  - p0737 ｜ 2025/11/04 ｜ 第 78 页（152 字，**截断帖**，结尾「这个社…」被截断；上引为可见部分，仅用于「现象→判断」顺序分析，**不作收尾结论依据**）

- **可执行的动作**：模板 `【1–3 个同主语的可观察现象/场景/案例，只描述不评价】。【末句用「说明 / 就是 / 说到底 / 这种…」落到判断】`。写时先把结论盖住，只留现象；读完现象若结论自己浮出来，顺序即成立。现象必须自带时间、人物或数字锚点（见候选 04/05），不能是抽象复述。
- **边界与失效场景**：判断若读者已普遍接受，现象前置会显得拖沓（此时用候选 01）；现象与判断之间没有可归纳关系时，会变成「硬拗」。**两个引用中 p0737、p0905 为截断帖，只取可见部分**；p0737 附带史实与价值判断，学其「现象→判断」顺序，不学其立场与数字。法律、医疗、财务文本里「现象→判断」属推断，需补严谨前提。

## 03 · 两种顺序的适用场景（决策规则）

- **type**：元规则 / 信息顺序选择
- **一句话概括**：结论可接受、读者不会抗拒 → 先给结论再补证据；结论反直觉、会引发「凭什么」→ 先摆现象再下判断；拿不准时现象前置更安全。
- **原文引用**（两条对照，均为完整帖全文；p0103 原文含错字「先做着」，照录不学）：
```
人一定是靠冷漠去赢得尊重的。你跟任何人的关系的好坏，从来不取决于你的善良和迎合，只看你的强弱，你必须强大到随时先做着的实力。你要记住，想要让自己变得更好，就别总想着对别人太好。
```
```
你喜欢别人的老婆，这样说，是不是显得你很坏？你喜欢的人，做了别人的老婆，这样是不是好一点？语言即世界。
```
- **出处**：
  - p0103 ｜ 2026/02/24 ｜ 第 13 页（89 字，完整帖，**结论前置**：首句即「人一定是靠冷漠去赢得尊重的」）
  - p0835 ｜ 2025/10/30 ｜ 第 88 页（52 字，完整帖，**现象前置**：两问后才落「语言即世界」）
  - p0627 ｜ 2025/11/12 ｜ 第 66 页（101 字，完整帖，结论前置 + 补证）
  - p0024 ｜ 2026/03/08 ｜ 第 6 页（150 字，完整帖，现象前置 + 史实）
- **频次 / 量化依据**：本条是决策规则，不单独计数；依据为候选 01/02 的检索（`因为` 919 行 / 810 帖、`所以` 453 行 / 430 帖、`？` 797 行、`其实` 524 行）与 `stats.md`「三句以内 2144 / 52.9%」—— 短帖容量只够一种顺序，二选一而非混排。
- **可执行的动作**：写之前先给结论打一个标签——`[读者已默认接受]` 用 `判断 → 一层补证`；`[读者会反驳/反直觉]` 用 `现象（≥2 个）→ 判断`；`[需免责/多因]` 两种都不用，改长文论证。决策表：

  | 结论性质 | 推荐顺序 | 骨架 |
  | --- | --- | --- |
  | 常识、强观点、可摘抄 | 先结论后补证据 | 判断 → 尤其是/因为 → 收判断 |
  | 反常识、翻案、会引发「凭什么」 | 先现象后下判断 | 现象/案例 ×2 → 说到底 → 判断 |
  | 需说服且结论可证伪 | 现象后再补证据 | 现象 → 判断 → 数字/案例支撑 |
  | 开放、多因、需免责 | **都不适用** | 长文分层论证 |

- **边界与失效场景**：同一帖内混用两种顺序（先结论、又绕回现象、再下第二个结论）会显得车轱辘话，短帖只选一种。反直觉结论若先抛，读者会在第一句就离场（`BOOK_OVERVIEW` 已注明断言密度极高、多数判断不给证伪条件）。**「说到底」类收束路标词与 `human-writing` 冲突，默认关闭，需复刻原帖风格时显式开启**。

## 04 · 用硬数字替掉抽象论证

- **type**：证据组织 / 量化替代
- **一句话概括**：把「很多 / 大多数 / 极高 / 差距大」这类抽象程度词，换成带单位、带量级、最好带时间锚的具体数字，让断言看起来被秤过。
- **原文引用**：
```
赚钱有四种模式：搞定10,000 个普通人，服务1,000 个中产，伺候100 个有钱人，成为1 个有权力人的子女。
```
```
学习的本质就是不断纠正错误的过程，纠错1000 次的价值，远高于重复1 万小时。生命中最稀缺的资源，并非时间，而是注意力。
```
- **出处**：
  - p0342 ｜ 2026/02/07 ｜ 第 36 页（59 字，完整帖；10,000 / 1,000 / 100 / 1 四级递减，把「赚钱模式」量化成可对照的数列）
  - p1378 ｜ 2025/09/28 ｜ 第 145 页（151 字，**截断帖**，结尾「超越99%的…」；上引为可见部分，「1000 次 / 1 万小时 / 99%」撑断言，原文含错字「源白」，照录不学）
  - p0470 ｜ 2025/11/21 ｜ 第 50 页（193 字，**截断帖**，结尾「(920 亿元人民…」；按年份列赴日游客数的编年数字）
  - p1289 ｜ 2025/10/03 ｜ 第 136 页（151 字，**截断帖**，「20%的时间试错 / 80%的时间复盘」）
- **频次 / 量化依据**：`stats.md` 含数字 **293 / 7.2%**；Grep `corpus.md` 硬数字模式（`[0-9]+ ?[亿万%倍]` / 供养率 / GDP / TWh / 美金 / 美元 / 人民币）**134 行**、`posts.jsonl` 同类模式 **98 帖**；`stats.md` 含冒号 666 / 16.4%（数字常与「四种模式：」「N 个方法：」共现）。注意 `corpus.md` 行数含版面数字，精确帖数以 `posts.jsonl` 为准。
- **可执行的动作**：模板 `【抽象判断】→ 把其中每个程度词换成「数字 + 单位 + （可选）时间/对象锚」→ 用 2–4 个量级形成递减/递增数列`。例：「要服务很多人」→「搞定 10,000 个普通人，服务 1,000 个中产」。数字之间最好有可比量级（10,000 / 1,000 / 100 / 1；1 万小时 / 1000 次），比孤立一个大数更有说服力。校验：一段里若出现「很多 / 大量 / 极高」而没有任何数字，即未启用此手法。
- **边界与失效场景**：**数字真伪不在本蒸馏范围**——学的是「用具体数字撑断言」的组织法，产物不得把原书人均供养率、赴日游客数、GDP 等当事实转述，也**不得凭空编造数字填空**。迁移到财报、研报、医疗、合规文本时数字必须可溯源，否则是硬伤；安慰、抒情、讣告类文本用数字会显冷硬。冒号「N 种模式：」按 `human-writing` 开关处理（见全局边界）。

## 05 · 用具体案例替掉抽象论证

- **type**：证据组织 / 案例承载
- **一句话概括**：不写「因为所以」的推演，改给一个带时间、人物、地点或数字的最小案例，让判断由案例自己托住，末句轻轻回扣。

- **type**：收束 / 翻案结论
- **一句话概括**：先破一个流行理解（「很多人以为 X」「按常理 X」），再用「其实 / 并不是 X，而是 Y / 而非」给出反直觉判断，收在最后一句，不补总结。
