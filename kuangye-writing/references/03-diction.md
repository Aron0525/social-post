## 维度口径与全局边界（非候选，不计入下方 11 条）

- **与 01 / 02 的分工**。01《结构与起收》管整帖骨架、开头与收尾类型；02《句式与节奏》管句长、标点配比、对仗、翻案、定义句的句法参数。本文件只管**词汇层**：选哪个词、给概念起什么名、拿什么打比方、把抽象词换成什么实物。与 02 重叠的「定义句 / 第一性原理 / 翻案」在此只从**词表与命名动作**角度处理，不复述标点与句法参数；与 04《论证组织》重叠的「硬数字」在此只作为「具体化」的素材，不归纳论证链。
- **量化基线**。`stats.md` / `BOOK_OVERVIEW.md`：4052 帖，2025/03/05–2026/03/09，正文 443705 字；高频起首四字「在中国，」37、「这个世界」31、「永远不要」17、「当一个人」17、「如果一个」15、「你有没有」14。**2025/12 与 2026/01 无数据，本文件不做任何时间演变判断。**
- **截断红线（最高优先级）**。1981 帖以省略号收尾且集中在 140–159 字，是推文字数上限造成的导出截断，**不是文风**。故：① 省略号绝不当手法；② 被截断帖的引用只用于**开头与句中**分析，绝不用于归纳收尾；③ 本文件凡引用截断帖，均在出处括号中显式标注「截断帖，引用取开头 / 句中」。完整帖 2071 条，真实舒适区 20–120 字。
- **规范冲突（必须显式告知）**。原书「说到底」等洞察路标词、商业黑话式术语（底层逻辑 / 赛道 / 闭环 / 第一性原理 / 杠杆）、「不是……而是……」翻案腔，与 Aron 现行 `human-writing` 硬规则（禁洞察路标词、禁商业黑话、禁翻案腔、禁冒号破折号）冲突。本文件把「说到底」类（候选 08）、术语借用（候选 10）、翻案式重定义（候选 04）一律登记为**「可识别、可选择」，默认不推荐、不启用**；需要复刻原帖风格时显式开开关，**绝不静默覆盖既有规范**。两套规则不能同时全量生效。
- **发布痕迹不学（不列为可学手法）**。原书错别字与病句属快速发布痕迹，引用一律照录原文以保证可回查，但学写法不学其字词：p0545「扶隘」「内人」、p0548「不是要协」、p0001「永远看完的电视剧」（疑为「看不完」）、p1378「源白」（应为「源自」）、p0767「展荡」「模顶」、p0663「成为是牛马」、p0103「强大到随时先做着的实力」、p2259 首字缺「一」。未经核实的硬数字（赴日游客数、人均供养率、各国总统任期等）不在本书蒸馏范围内，只学「用具体数字撑断言」，不学数字真伪。
- **只归纳可迁移的写法**。本文件不含「模仿作者人设」「扮演作者」「复刻冷感语气」一类内容；语气位置、骨架、句法归其他维度。全部候选均给出可直接复用的**词表**与**句式槽位**，供生成 / 改写 / 校验三类用途取用。

## 01 · 比喻取材（一）：生活物件、身体与器物

- **type**：修辞手法 / 明喻与暗喻（词汇选型）
- **一句话概括**：把抽象状态钉在一个可触摸的生活物件或身体动作上（毒药、镜子、电视剧、刀、刹车片、船、原材料），用「是 / 像 / 变成」直接连，不解释相似点。
- **原文引用**：
```
【p1107】自卑是让你一辈子跪着活的毒药，他让你在机会面前自动退缩，在喜欢的人面前觉得自己是垃圾，连别人夸你都觉得是在讽刺，你活的像个永远在道歉的罪犯。
【p0468】心就像一面镜子，映照他人，映照万物。成年人的心是被染著五欲六尘的，像个傀儡，被外物和欲望蒙蔽本心。
```
- **出处**：
  - p1107 ｜ 2025/10/14 ｜ 第 117 页（143 字，截断帖，引用取开头；「毒药 / 罪犯」暗喻）
  - p0468 ｜ 2025/11/21 ｜ 第 49 页（143 字，截断帖，引用取句中；「镜子 / 傀儡」明喻）
  - p0001 ｜ 2026/03/09 ｜ 第 4 页（94 字，完整帖，「把自己变成一个永远看完的电视剧」，「看完」疑为错字，照录不学）
  - p1076 ｜ 2025/10/15 ｜ 第 114 页（51 字，完整帖，「（加速度）……（刹车片）」汽车零件作比）
  - p3085 ｜ 2025/06/07 ｜ 第 320 页（115 字，完整帖，「同样一把刀，你想着是做饭，我想的是作战」）
- **频次 / 量化依据**：Grep `corpus.md` 比喻标记组（就像\|好比\|如同\|当成\|当作\|韭菜\|棋子\|镜子\|牛马\|燃料\|原材料\|像一面）**248 行**、`posts.jsonl` **220 帖 / 5.4%**；该口径未含「是 / 变成」类暗喻，实际覆盖率更高。器物 / 身体类另见 p1524「像一艘船」、p0382「人格重塑的原材料」。
- **可执行的动作**：词表 —— 器物（镜子、傀儡、刀、船、刹车片、加速度、电视剧、原材料）、身体身份（跪着活、罪犯、牛马、打手、血包、老狐狸）。槽位 —— `【抽象名词】是【一件具体物 / 一个身体动作】`、`把【自己 / 关系】变成【器物】`、`像【器物】一样【动作】`。生成时先写下要说的抽象词（自卑、心、关系），再从词表挑一个质感相反的具象物替换，删掉「好比说」「这就好像」这类解释连接。**校验**：脚本检测一帖内是否出现 ≥1 个具象名词 + 1 个「是 / 像 / 变成」系词，若全是抽象名词则报「缺具象锚点」。
- **边界与失效场景**：一帖只承载一个比喻，两个以上会互相打架；暗喻要求读者自己补齐相似点，用于陌生概念或需精确定义的说明文会失真；「像」字句在正式报告、法律、科普里显轻浮。冷感文体以外的安慰、致谢、讣告文本禁用「毒药 / 罪犯 / 牛马」这类带贬损的具象物。被截断帖 p1107 / p0468 的引用只取开头与句中，不据此归纳收尾。

## 02 · 比喻取材（二）：动物、自然场景与商业场景

- **type**：修辞手法 / 场景类比（词汇选型）
- **一句话概括**：把「博弈 / 关系 / 人性」先翻译成一个自带结论的具体场景（牌桌、田野、厨房、战场），再让场景里的角色替你说判断。
- **原文引用**：
```
【p2130】目标是穿过沼泽地，不是对付每一条鳄鱼。人不要着了相，不要太纠结一时的得与失。
【p0510】在币圈，说到底就是一场高智商博弈，但再聪明的投机者、再牛逼的链上赌神，在真正的做局者面前也只是韭菜。
```
- **出处**：
  - p2130 ｜ 2025/08/17 ｜ 第 222 页（38 字，完整帖，「沼泽地 / 鳄鱼」自然场景作比）
  - p0510 ｜ 2025/11/19 ｜ 第 54 页（157 字，截断帖，引用取开头；「韭菜 / 做局者 / 收割 / 高杠杆」商业场景）
  - p3107 ｜ 2025/06/05 ｜ 第 323 页（118 字，完整帖，「凡是从画饼开始的，都是以卸磨告终」）
  - p2455 ｜ 2025/07/25 ｜ 第 255 页（143 字，截断帖，「世世代代被当韭菜」）
  - p0111 ｜ 2026/02/23 ｜ 第 14 页（27 字，完整帖，「消耗你的局」）
- **频次 / 量化依据**：同 01 的比喻标记组 `corpus.md` **248 行** / `posts.jsonl` **220 帖**；`corpus.md` 口语冷感词（牛逼\|…\|画饼）**55 行**、`posts.jsonl` 含韭菜 / 收割的口语商业词 **64 帖 / 1.6%**；`corpus.md` 造词组含「局」类 **88 行**、`posts.jsonl` **66 帖**。
- **可执行的动作**：词表 —— 动物自然（韭菜、牛马、棋子、鳄鱼、沼泽、狗链子、花、木头与火）、商业场景（做局者、入局 / 破局、收割、画饼、卸磨、杠杆、止损、高杠杆梭哈、血包）。槽位 —— `目标是【穿过某场景】，不是【对付每一条障碍】`、`在【某圈子】，再【厉害角色】也只是【被收割物】`、`凡是【话术A】开始的，都是以【动作B】告终`。改写时把「竞争 / 博弈 / 消耗」替换成一个具体场景名，让场景自带胜负结论，不写「这说明」。
- **边界与失效场景**：⚠️ 商业场景词（韭菜、收割、做局、杠杆）与 Aron 现行 `human-writing`「禁商业黑话」冲突，登记为**可识别、可选**，默认不启用；面向普通读者的科普、客服、安慰文本里「韭菜 / 收割」带冒犯性，直接失效；「鳄鱼 / 沼泽」类场景比喻需读者熟悉该场景，跨文化背景会落空。p0510 / p2455 为截断帖，引用只取开头与句中。
