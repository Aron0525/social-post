# 旷野体写作手法

## 使命

把《旷野之心》正文 4052 条短帖里的写法，变成生成、改写、校验、扮演、画像五条路径上可直接执行的动作。这套写法为 20 至 120 字的独立短帖优化，目标是让一个判断能被单独摘抄和单独转发。

产物既归纳可迁移的写法，也支持扮演作者 Morris 说话，还能生成他的个人画像与协作风格卡。角色扮演走路径四，人设卡走路径五，两条路径复用同一批能力卡。错别字与未经核实的数字两类都不继承。

## 调用判断

用之前先判载体。

- 适用。20 至 120 字的独立短帖、金句、标题、一组同主题短帖、把一段松散议论收紧。
- 局部适用。长文里的句子收紧、删铺垫、改第二人称。只借 `mirror-pair` 与 `stance` 两条，其余停用。
- 角色扮演。用户点名要用 Morris 口吻、扮演作者或让作者回答问题时启用路径四。默认仍按 `strict_default_on` 走，除非用户单独要求连原帖标点一起复刻。
- 人设卡。用户要作者个人画像、协作风格、人设卡时启用路径五，产出或复用 `PERSONA.md`。这张卡也是路径四的依据。
- 停用。长文、研报、科普、教程、论文、致谢、讣告、客服回复、需要出处与证伪条件的文本、需要合作与共情语气的沟通。安慰类场景尤其危险，冷感笃定语气会读成指责。

再判结论。读者已默认接受，走「判断 → 一层补证」。结论反直觉，走「现象（≥2 个）→ 判断」。需要免责或多因分析，两种都不走，改长文论证。

## 开关 strict_default_on

默认 `true`，遵守 Aron 现行 `human-writing` 规范。此状态下关闭以下手法。

- 中文冒号与冒号定义句。改用句号或换行。
- 翻案句 `不是……而是……`、`才是`、`并非……而在于` 及同类。改成正面陈述。
- 破折号、`说到底` 类洞察路标词、商业黑话与模型黑话。
- 三项以上同构排比。最多两项。

同时把绝对化断言标为断言项，输出时提示人工确认是否需要补限定条件。

用户明确要求复刻原帖风格时才置 `false`。校验脚本的 `--no-strict` 只放开中文冒号与翻案句两项，感叹号、破折号、省略号、洞察路标词、商业黑话、行动号召、总结段始终判 FAIL，原书这些用法的占比都在 3% 以下。放开后在输出末尾附一行冲突提示，写清本次放开了哪几项。绝不静默覆盖现行规范。

## 八条能力

详细六段卡在 `capabilities/cards/`，量化依据与出处在 `references/`。整个交付包自包含，复制目录即可安装。

| 能力 | 一句话 | 完成标准 |
| --- | --- | --- |
| `single-sentence` 单句成帖 | 一个可摘抄的判断，不写第二句 | 句末标点恰好 1 个，18 至 34 字 |
| `assert-first` 断言领起 | 首句下判断，只补一层细化或依据 | 首句无情态词，补证恰好 1 层 |
| `mirror-pair` 两句对举 | 造字数相近、结构镜像的短句 | 字数差 ≤3，无连接词，恰好 2 项 |
| `question-hook` 设问自答 | 问句压在首句，第二句立刻自答 | 问句 ≤20 字，以问号收尾 0 次 |
| `numbered-list` 编号清单 | 先报总数再逐项给短语 | 项数 3 至 5，总长 ≤120 字，无总结段 |
| `concrete-anchor` 具体锚 | 抽象程度词换成可数对象与最小案例 | 无「很多人／通常／极高」，数字标来源 |
| `closing` 收尾四型 | 金句、回扣、动作、留白任选其一 | 末句 ≤25 字，无总结段，不用省略号 |
| `stance` 语气与第二人称 | 删情态词，改「你」，全称判断 | 无情态词，感叹号 0，破折号 0 |

能力之间有互斥关系。`single-sentence` 与 `assert-first` 互斥，出现第二句即转后者。`mirror-pair` 恰好两项，`numbered-list` 项数 3 至 5。`closing` 只处理末句，`stance` 只处理词汇与语气。完整链接表见 `audit/CAPABILITY_CARDS.md` 末尾。

## 路径一 生成

1. 判载体与结论类型，见上面的调用判断。停用场景直接说明原因并退出。
2. 从八条能力里选 1 至 2 个组合。常见组合有 `single-sentence` 单用、`assert-first` 配 `concrete-anchor`、`question-hook` 配 `numbered-list`、`mirror-pair` 配 `closing`。
3. 按「3 句 × 25 字 ≈ 75 字」起稿。首句直接落判断，删掉所有引导句。逗号串 3 至 5 个 6 至 12 字短分句，句号只留收束处。
4. 收尾用倒着删。删「所以综上」「总之」「以上就是」「希望能帮到你」「愿你」，末句压到 10 至 25 字，单独摘出仍成立即合格。
5. 跑 `scripts/check_style.py` 看报告，处理所有 FAIL，WARN 逐条判断。
6. 输出纯文本，不附加解释、不附加标题、不附加「以上」。若 `strict_default_on` 为 false，末尾附一行冲突提示。

## 路径二 改写

按这个顺序逐条过，每一步只做一件事。

1. 删铺垫与引导句，首句直接落判断。
2. 删「可能」「也许」「大概」「似乎」「我认为」「某种程度上」。保留原文里必要的严谨限定，不为力度删条件。
3. 把「人们」「一个人」「很多人」改成「你」，补一个正在发生的具体处境。
4. 圈出抽象程度词与抽象名词，换成数字、年龄、物件、具体场景或可数动作。数字须用户提供，缺失就标「待核实」。
5. 把带「因为」「而且」「并且」的长复合句拆成逗号短分句，每分句只放一个动作或状态。
6. 删末段总结与行动号召，按 `closing` 四型改写末句。
7. 输出改写稿加一份变更清单，逐项写清改了什么、依据哪条能力。跑脚本校验。

## 路径三 校验

```
python scripts/check_style.py <稿件路径>
python scripts/check_style.py <稿件路径> --json
python scripts/check_style.py <稿件路径> --no-strict
python scripts/check_style.py <稿件路径> --corpus
type 稿件.txt | python scripts/check_style.py -
```

脚本只读输入，不改动原文件，不联网，不删除任何东西。报告分 FAIL 与 WARN 两级。FAIL 对应硬规则违规，WARN 对应风格偏离。语料模式下遇到以省略号收尾的段落直接跳过并计入跳过数，不参与收尾统计。

## 路径四 扮演作者

用户点名要用 Morris 的口吻、让作者回答问题、或按《旷野之心》的语气写一段时走这条路径。它与前三条路径共用同一批能力卡，另加一层人设约束。

1. 先确认请求确实指向角色扮演。只说「语气硬一点」「收一下尾」的仍是改写，走路径二。
2. 取 `stance` 打底，删情态词、改第二人称、下全称判断。按主题再配 `mirror-pair` 或 `assert-first`，必要时用 `closing` 收尾。
3. 用词取 `references/03-diction.md` 的受限词表与第二人称呼语，句子骨架取 `references/01-structure.md`，句长与标点按硬规则执行。
4. 只写语料里已有的判断类型。原书谈的是关系、金钱、自我处境、成长，遇到书里没有的领域就说明没有依据，不替作者编观点。
5. 不复用原书未经核实的数字与错别字，不冒用真实账号身份，不写「我就是 Morris」这类身份声明，不针对真实第三人做人身评判。
6. 输出末尾附一行标注「按《旷野之心》文风拟写，非作者本人观点」。
7. 跑 `scripts/check_style.py` 处理所有 FAIL。

角色扮演不改变 `strict_default_on` 的默认值。用户要连冒号定义句、翻案句一起复刻时，单独说明并显式置 false，末尾附冲突提示。

## 路径五 生成作者画像与协作风格

用户要「作者个人画像」「协作风格」「人设卡」时走这条路径。交付包里已有一份基于全书语料生成的 `PERSONA.md`，默认先读它，再按用户需求裁剪或补充。

1. 先读 `PERSONA.md` 与 `audit/persona_stats.md`，确认 A / B / C 三层标注。用户只要某一维时，从卡里抽对应字段，不重写全卡。
2. 要重算证据时跑 `scripts/analyze_persona.py`。脚本读 `data/posts.jsonl`，纯本地只读，输出覆盖 `audit/persona_stats.md`。也可把源工作区的 `posts.jsonl` 路径作为第一个参数传入。
3. 每个结论都要能回查。A 层给帖子 id、日期、页码与频次，B 层明写推导依据，C 层写「语料未覆盖，不推断」。
4. 协作风格九维逐条给可执行约定。开场、信息密度、提问、给反馈、处理分歧、不确定性、拒绝、情绪、收尾。单向发布的语料没有对话记录，这九项都是设计约定，不是作者真实互动实录。
5. 用户另外给出生平、职业、真实聊天记录时，可把对应字段从 C 或 B 升到 A，注明材料来源与时间，与原有结论并列保留，不覆盖。
6. 不补生平，不复用原书未核实数字，不冒用真实账号身份，不把书里的观点写成作者经历。
7. 生成的卡供路径四扮演时取用。扮演文本末尾仍要标注非本人观点。

`PERSONA.md` 是产物也是输入。用户以后给出新材料时按第 5 条增量更新，并把变更记进 `audit/PIPELINE_STATE.md`。

## 硬规则

1. 句长 12 至 30 字，超过 40 字报警。
2. 每帖 1 至 3 句，总长 20 至 120 字。
3. 逗号与句号比 2 比 1 至 3 比 1，超过 5 比 1 判为流水句。
4. 默认只用逗号和句号。感叹号 0，破折号 0，省略号 0。
5. 问句只放首句，约每 6 帖 1 问，以问号收尾 0 次。
6. `strict_default_on` 为 true 时，冒号、翻案句、路标词、三项以上排比全部判 FAIL。
7. 不写行动号召，不写总结段，不写「希望对你有帮助」。
8. 涉及事实的数字必须用户提供或标注来源。原书数字一律不复用。
9. 绝对化断言标为断言项，合规、医疗、投资、法律、新闻类内容直接停用整条手法。
10. 引用原书例句时保持原文错字并标注，生成稿按规范用字。
11. 扮演作者时按路径四执行，输出末尾必须标注非本人观点，不冒用真实账号身份，不替作者编造语料里没有的观点。
12. 生成人设卡时按路径五执行，三层证据标注齐全，C 层不推断，B 层不写成事实，协作风格不冒充真实互动实录。

## 不学清单

- 以省略号收尾。1981 帖占 48.9%，全是 140 字上限造成的导出截断，属于假特征。
- 错别字与病句。「扶隘」「内人」「永远看完」「不是要协」是发布痕迹。
- 未经核实的硬数字。赴日游客数、人均供养率、总统任期等，来源未标注。
- 无出处的绝对化断言。原书 33.8% 的帖子带绝对化词且多不给证伪条件，这是最大迁移风险。
- 冒充真实账号身份，以及替作者编造语料里没有的观点。角色扮演已放开，走路径四，只复刻可回查的表达习惯。
