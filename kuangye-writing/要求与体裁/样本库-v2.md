## S01 冷知识型

```text
冷知识，

Codex Pro 200 每消耗 1% 的额度，就相当于 Plus 消耗 20%，

相当于Pro 用户随手烧掉 5%，Plus 用户的一整份周额度就没了。
```

| 项 | 内容 |
| --- | --- |
| 钩子 | 冷知识，四字加逗号，独立成行，承诺一个你大概率不知道的事 |
| 主体 | 两级换算。先给比例差 1% 对 20%，再落到 5% 对一整份额度 |
| 收口 | 把比例换成读者的实际损失，没有形容词 |
| 排版 | 三块，每块之间空行。原文第二行以逗号断，不写句号 |
| 特征 | 全篇只讲一个数字关系，没有任何背景交代 |

## S02 佩服加人数型

```text
在X上有三种人，我是真的佩服：

1、每天发帖50+的人。
2、每天手搓评论1000+的人。
3、把前两件事每天坚持下来，
       而且一天都不落的人。

这种狠人，每个月拿不到3000美金+，
马斯克你良心不会痛吗？！
```

| 项 | 内容 |
| --- | --- |
| 钩子 | 人群分类加态度词，我是真的佩服，冒号收尾，摆出要爆料的样子 |
| 主体 | 三条编号，严格递进。第三条是前两条的叠加，并且跨行缩进，制造视觉停顿 |
| 收口 | 反问加？！，点名具体的人，情绪一次性放完 |
| 排版 | 首行独立，编号列表独立成块，收尾两行断句 |
| 特征 | 数字用加号写法 50+、1000+、3000美金+，口语混书面 |

## S03 扎心提问型

```text
一个扎心的问题：

为什么美国富豪很少考虑移民中国，而中国富豪却想方设法移民美国？

同样是有钱人，为什么选择截然不同？
```

| 项 | 内容 |
| --- | --- |
| 钩子 | 情绪标签加冒号，扎心，先给读者的感受定调 |
| 主体 | 一个对照问句，A 不做 X 而 B 做 Y，用身份对举 |
| 收口 | 第二问，把第一问压缩成一句反问，不给答案，逼评论区回答 |
| 排版 | 三块，极短，净 56 字 |
| 特征 | 全文没有一个陈述句，纯提问。信息量为零，讨论量最大 |

## S04 真心建议型

```text
真心建议大家：让自己暴露在机会中

运气其实就是曝光度。多旅行，尝试一家新的咖啡店，去街上与感兴趣的异性搭讪，和散步的老人聊聊，在X发文，培养一个新爱好。如果你一直保持相同的日常，周围是相同的人，做相同的事情，什么都不会发生。你通过让更多事物进入你的生活来创造机会。走出去，大胆一点。世界会奖励行动者
```

| 项 | 内容 |
| --- | --- |
| 钩子 | 真心建议大家加冒号加一句主张，钩子和标题合一 |
| 主体 | 先一句定义式断言（运气就是曝光度），再逗号串六个具体动作，再一个假设推演最坏结果 |
| 收口 | 三连短句，走出去、大胆一点、世界会奖励行动者，最后一句无标点 |
| 排版 | 只有两块，正文一整段不空行，靠逗号制造节奏 |
| 特征 | 全文 148 字，四篇里最长，但只有一个意思，不扩写不解释 |

## S05 示弱求教型

```text
不懂就问：

粉丝有1万，

一条帖子只有100次曝光。

这正常吗？
```

| 项 | 内容 |
| --- | --- |
| 钩子 | 不懂就问，五字加冒号。主动放低姿态，把自己写成求助者 |
| 主体 | 三个数据点各自独立成块，一行一个，行行空行。不是段落，是读数 |
| 收口 | 单问，五字这正常吗，不给自己的判断 |
| 排版 | 四块，每块最长 24 字，最短 5 字。视觉上一顿一顿往下掉 |
| 特征 | 全篇 29 字，七条里最短。信息量极小，共鸣面极大，同类困境的人会主动进评论区报数 |

## S06 名人引用加反转型

```text
陈丹青说过这么一段话：

美国人为什么乐意接纳大批中国富人移民？

因为在他们的认知里，能成为富人的都是精英：脑子好、有道德、有文化、讲诚信、肯担当、有责任心，还带着贵族精神——不然，凭什么能发财呢？

结果大批中国富人真搬过去之后，美国人傻眼了：这帮人自私、贪婪、奸诈、粗鄙、势利眼，一点诚信都没有。美国人怎么也想不通：这种下三滥，是怎么混成有钱人的？

其实是美国人不懂中国。在中国想成为有钱人，靠的恰恰是另一套“基本素质”：坑蒙拐骗、歪门邪道、请客送礼、溜须拍马。不会这些，你根本不可能成为有钱人！
```

| 项 | 内容 |
| --- | --- |
| 钩子 | 名人加转述，十一个字加冒号。借第三方的嘴开场，作者先不表态 |
| 主体 | 三段反转。第一段给美国人的预期，第二段给现实打脸，第三段给归因 |
| 收口 | 定性断言加感叹号，你根本不可能成为有钱人 |
| 排版 | 五块，块长从 11 字到 73 字，末块最长 |
| 特征 | 全篇 244 字，七条里最长。前四块都在复述别人的观点，作者只在最后一块下判断，责任转移得很干净。用了破折号、弯引号、感叹号各一处，是七条里符号最重的一条 |
| 风险 | 涉及群体贬损和地域刻板印象，转发高但投诉也高。生成同类内容必须换成不指向具体人群的题材 |

## S07 暴论加算账型

```text
说个暴论：

BTC 现在已经跟普通人没什么关系了。就算你买一个，它涨了 10 倍，按照现在的价格大概 66万美金，也只够买一套差不多一点的房子。

我们普通人应该怎么做呢？我觉得我们应该找到下一个BNB ？

下一个BNB 会是哪个 ？
```

| 项 | 内容 |
| --- | --- |
| 钩子 | 说个暴论，五字加冒号。预先声明接下来要说难听的 |
| 主体 | 先下判断，再用一次算账把判断坐实。买一个、涨十倍、折成 66 万美金、等于一套房，四步换算成生活物件 |
| 收口 | 连问两遍。第一问自答，第二问单独成行抛给读者 |
| 排版 | 四块。最后一个问句独立成块，前面留白更足 |
| 特征 | 106 字。中段用了我觉得，是七条里少见的直接表态。原文有空格和问号前置的瑕疵（BNB 后空格、问号前空格），原样保留 |

## 存档规则

1. 新样本按 S05、S06 顺延编号，追加在文末，不改已有条目
2. 每条都补一张标注表，四个字段固定：钩子、主体、收口、排版
3. 原文放代码块，防止格式被 Markdown 吃掉
4. 统计表同步加行，保持可横向比较
5. 生成时只借结构，不复制错字、缺空格、加号计数这类发布痕迹
