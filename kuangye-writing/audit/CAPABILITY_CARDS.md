## cap.kuangye.single-sentence 单句成帖

### R 原文

```
什么都不图你的人，离开的时候最干脆。
```
`p0058 | 2026/02/28 | 第 9 页 | 18 字 | 完整帖`

```
语言是用来修饰世界，行动才是用来暴露真心。
```
`p0204 | 2026/02/17 | 第 23 页 | 21 字 | 完整帖`

### I 自述

把整帖压成一个能被单独摘抄的判断。不交代背景，不给理由，不写第二句。句子里通常有一组对举的名词，靠名词之间的落差把判断撑起来。全书 628 帖只有一个句末标点占 15.5%，其中 21 帖连逗号都没有。这个能力是其它所有能力的基线，先问能不能一句说死，能就停笔。

### A1 书中案例

`p0003 | 2026/03/09 | 第 4 页` 用一个可观察的生活细节直接落判断。

```
如果你有精致的衣服却不穿，说明你的生存环境和工作环境，与衣服不匹配。
```

### A2 未来触发

场景包括给一个主题要一条短帖、要把一段长文压成一句话、要写金句或标题。语言信号有「一句话说清」「帮我写条帖子」「压成金句」「短一点」。与 `assert-first` 的区别在于这里不允许出现第二句，一旦需要补证就转 `assert-first`。与 `closing` 的区别在于这里处理整帖，`closing` 只处理末句。

### E 执行

1. 读输入，抽取一个可判断的对象和一个落差关系。缺失则问用户要主题，不猜。
2. 写一句 18 至 34 字的陈述判断，动词用「是」「说明」「才算」「最」，删情态词与引导语。
3. 检查句末标点数为 1，检查脱离上下文仍成立。成立即输出并停笔。

输入契约，主题字符串，可选一个具体物件。输出契约，单句纯文本，无标题无编号。完成标准，句末标点恰好 1 个，字数 18 至 34。

### B 边界

需要论证、数据、免责、致谢、安慰、客服、科普的文本不用。判断本身反直觉时不单句成帖，转 `assert-first` 或 `question-hook`。原文里的错别字不学。

## cap.kuangye.assert-first 断言领起加一层补证

### R 原文

```
喜欢开口借钱的人，人品往往都有问题。尤其是已成年，却还向朋友、亲戚、家人借钱的，而且借的还都是几百几千这种小钱。你放心，指望这种人还钱，是不可能的。
```
`p0627 | 2025/11/12 | 第 66 页 | 完整帖`

### I 自述

第一句直接下判断，第二句只做一件事，细化对象、给一句依据或用第二人称担保。第三句若有，收在判断上，不另开话题。`因为` 在全书出现 810 帖占 20.0%，`所以` 430 帖占 10.6%，补证层几乎是这套文体的标配。关键是只补一层，补到两层就滑向论证长文。

### A1 书中案例

`p0001 | 2026/03/09 | 第 4 页` 判断之后补的是后果链，再补一个设问自答。

```
跟任何人，都要少说话，少分享。你一旦让别人知道你太多事，他们就会慢慢看清你，不尊重你，最后关系还会变差。
```

### A2 未来触发

场景包括写 2 至 3 句短帖、把一段松散议论收紧、给观点补一句支撑。语言信号有「展开一点」「补个理由」「两三句话」。与 `concrete-anchor` 的区别在于这里补的是细化或担保，那里补的是硬数字与最小案例。与 `single-sentence` 互斥，出现第二句即属本卡。

### E 执行

1. 写一句不带「可能」「也许」「我认为」的判断。
2. 从细化对象、给依据、第二人称担保三选一，只补一层，压在 25 字内。
3. 第三句若写，收在判断，不写「综上」「总之」「希望对你有帮助」。

输入契约，主题字符串，补证类型可指定。输出契约，2 至 3 句纯文本。完成标准，首句无情态词，补证层数恰好 1，无总结段。

### B 边界

需要多因分析、需要给出处与证伪条件的文本不用。结论会让读者反驳时改用现象前置，见 `references/04-argument.md` 候选 02。

## cap.kuangye.mirror-pair 两句对举与对称

### R 原文

```
黑夜与白昼，对于一个盲人来说都是一样的；真理和谬论，对于一个无知的人来说并无分别。
```
`p0159 | 2026/02/20 | 第 19 页 | 完整帖`

```
别人找你之前，预判他的目的。别人开口之前，预判他的情绪。
```
`p0004 | 2026/03/09 | 第 4 页 | 完整帖`

### I 自述

造两个字数相近、结构镜像的短句并置，靠重复的语法位置替掉连接词。关键词通常成反义或分层。全书含分号并列 221 帖占 5.5%，`越 A 越 B` 命中 317 帖占 7.8%，对称是这本书最省力的加重方式。中间不写「这说明」「由此可见」。

### A1 书中案例

`p0005 | 2026/03/09 | 第 4 页` 四组同构短句，槽位只换动词与宾语。

```
故意共情，引你倾诉。故意捧高，等你膨胀。故意晒场，等你安慰。故意追问，等你松口。
```

### A2 未来触发

场景包括想把一句话写得更硬、需要并列出两种情况、要把抽象对照落到具体。语言信号有「对仗一点」「两句对照」「写得更整齐」。与 `numbered-list` 的区别在于这里只有两项且不用编号。与 `stance` 的区别在于这里处理句法，那里处理用词。

### E 执行

1. 写出第一句，记下主语框架与字数。
2. 造镜像句，共用框架，替换关键形容词或宾语，两句字数差 ≤3 字。
3. 中间只用句号或分号，删连接词。现行规范下同构排比最多两项，不到第三项就停。

输入契约，一个判断或一对概念。输出契约，两句纯文本。完成标准，字数差 ≤3，无解释性连接词，项数恰好 2。

### B 边界

`strict_default_on` 开启时不得写到第三项。分号默认改写为句号。真并列才用，硬凑会读成排比腔。

## cap.kuangye.question-hook 设问自答钩子

### R 原文

```
那说太多的人，如何保护自己呢？就是让自己变的丰富，把自己变成一个永远看完的电视剧。
```
`p0001 | 2026/03/09 | 第 4 页 | 完整帖`（原文「永远看完」为发布错字，照录不学）

### I 自述

用「为什么」「什么是」「如何判断」「你有没有」起句，问句压在 20 字内，紧接着自己回答。全书含问号 695 帖占 17.2%，而以问号收尾仅 12 帖占 0.3%，设问只做开头钩子，从不留给读者。`为什么` 命中 288 帖，`因为` 810 帖，问句后面通常跟一个单一根因。

### A1 书中案例

`p0024 | 2026/03/08 | 第 6 页` 问句开头后立刻给具体年份与执照编号作自答。

```
你知道吗？中国那些百年老店，都不是百年前的老店的样子
```

### A2 未来触发

场景包括主题过于平淡需要抓取力、要解释一个反直觉现象、读者可能带着疑问进入。语言信号有「开头抓人一点」「用提问开头」「为什么」。与 `assert-first` 的区别在于首句是问句，判断后置。与 `concrete-anchor` 常配合，自答部分交给具体数字或案例。

### E 执行

1. 把主题改写成 ≤20 字的问句，同一主语，只问能笃定回答的题。
2. 第二句立刻给一个根因，不写「答案很复杂」「因人而异」。
3. 需要铺开时借用 `numbered-list` 或 `concrete-anchor`，末句收在陈述判断。

输入契约，主题字符串。输出契约，2 至 4 句纯文本，问句在首句。完成标准，问句 ≤20 字，以问号收尾 0 次，无开放提问。

### B 边界

访谈、引导讨论、开放式提问的文本不用。约每 6 帖 1 问是全书基线，一稿内问句明显超标即报。

## cap.kuangye.numbered-list 编号清单体

### R 原文

```
赚钱有四种模式：搞定10,000 个普通人，服务1,000 个中产，伺候100 个有钱人，成为1 个有权力人的子女。
```
`p0342 | 2026/02/07 | 第 36 页 | 完整帖`（冒号为原书用法，默认开关下改写为句号）

### I 自述

先报一个总数，再逐项给 8 至 20 字短语。项内不展开，项间不写连接词，末尾不写总结段。全书 `第一…第二` 命中 90 帖，数字编号与顿号列举二选一，不混用。这类长帖最容易撞上 140 字上限，写的时候要主动控总长，别等被截断。

### A1 书中案例

`p0009 | 2026/03/09 | 第 4 页` 五步循环，每步一个动作，没有解释句。原帖以省略号收尾，此处只取可见的骨架部分。

```
创业等于这五件事反复循环：第一、发现一个真实存在的需求，第二、用最低成本给出一个可用解法
```

### A2 未来触发

场景包括一个主题下有 3 至 5 个平行要点、要写方法论清单、要把散点收成一组。语言信号有「列几条」「三个方法」「有哪几种」。与 `mirror-pair` 的区别在于项数 ≥3 且报总数。与 `concrete-anchor` 的区别在于这里靠结构承载，那里靠证据承载。

### E 执行

1. 定项数 3 至 5，确认各项互斥且同一层级。
2. 写报数句，默认用句号，不用冒号。
3. 逐项给 8 至 20 字短语，只换槽位词，项间不写连接词，末项后不加解释。

输入契约，主题与要点数组。输出契约，一段纯文本，总长 ≤120 字。完成标准，项数与报数一致，无总结段，无省略号收尾。

### B 边界

原书这类帖子近半数被 140 字上限截断，禁止据此归纳收尾。需要展开每一项时改用长文，不硬塞进短帖。

## cap.kuangye.concrete-anchor 硬数字与最小案例

### R 原文

```
舍得把自己重要的东西给对方才是爱，比如学生时代的金钱，有事业后的时间，性格急躁的人拿出的耐心，自卑敏感的人勇敢放下的面子。
```
`p1308 | 2025/10/02 | 第 138 页 | 完整帖`

### I 自述

把「很多」「通常」「极高」这类抽象程度词换成可数对象。一个最小案例要带时间、人物、地点或数字里的至少两项，只写事实不写评价。全书含数字 293 帖占 7.2%，含举例标记仅 113 帖占 2.8%，这本书不靠「比如」引导论证，靠具名事实本身托住判断。比喻取材偏爱生活物件与身体动作，比喻标记组命中 220 帖占 5.4%。

### A1 书中案例

`p0024 | 2026/03/08 | 第 6 页` 用年份、执照与法条废止时间替掉「大多数老店是假的」这种程度词。

```
北京市第一个个体工商户“悦宾饭馆”营业执照是1980 年发放的。
```

### A2 未来触发

场景包括判断太空、读者会问凭什么、需要给断言一个可核查的锚。语言信号有「具体一点」「举个例子」「有数据吗」。与 `assert-first` 常配合，那里定顺序，这里定证据形态。与 `numbered-list` 的区别在于不报总数。

### E 执行

1. 圈出稿子里的抽象程度词与抽象名词，列成待替换清单。
2. 逐项换成数字、年龄、物件、具体场景或可数动作。数字须由用户提供或另行核实，不得复用原书数字，不得编造。
3. 检查删掉这个锚之后判断是否仍一模一样地成立。成立说明锚没承重，换更具体的。

输入契约，草稿文本，可选用户提供的真实数字。输出契约，改写后文本加一份替换清单。完成标准，无「很多人」「通常」「极高」类程度词，所有数字标注来源或标记待核实。

### B 边界

原书部分硬数字未经核实，只学手法不继承数字。与现行 human-writing「现实内容不编造」硬规则一致，列为最高优先级约束。医疗、投资、法律、新闻类内容禁止无出处数字。

## cap.kuangye.closing 收尾四型

### R 原文

```
一个人只要不停下来，去处理那些不影响你前进的问题。只管向前走，你会发现，你的人生其实并没有什么问题。
```
`p0278 | 2026/02/11 | 第 30 页 | 完整帖`

```
永远不要让别人欠你的钱，要学会让别人欠你的情。
```
`p0012 | 2026/03/09 | 第 5 页 | 完整帖`

### I 自述

末句停在判断上，四种收法任选其一。金句判断可单独摘抄，回扣开头复现关键词，落到动作给一个今天就能做的祈使句，留白只留一个 4 至 8 字短句。全书以句号收尾 1996 帖占 49.3%，以问号收尾仅 0.3%，行动号召措辞仅 0.8%。收尾分析基线是 2071 条完整帖，被截断的 1981 帖一律排除。

### A1 书中案例

`p0111 | 2026/02/23 | 第 14 页` 金句判断型，末句脱离前文仍成立。

```
赢了不是厉害，主动退出那些消耗你的局，才是真正的厉害。
```

### A2 未来触发

场景包括稿子结尾拖了总结段、写了「希望对你有帮助」、末句软。语言信号有「收一下」「结尾硬一点」「删掉总结」。与 `single-sentence` 的区别在于这里只处理末句。与 `mirror-pair` 的区别在于收尾不新造对举。

### E 执行

1. 倒着删，删掉「所以综上」「总之」「以上就是」「希望能帮到你」「愿你」。
2. 从金句判断、回扣、动作、留白四型里选一型，改写末句，压在 10 至 25 字。
3. 把末句单独复制到别处，脱离上下文仍成立即合格。检查末句不带「吧」「哦」「呢」，不带「因为」「所以」「这就是」。

输入契约，草稿文本，可选收尾类型。输出契约，改写后全文与所用收尾型。完成标准，无总结段，无行动号召，末句 ≤25 字，不用省略号。

### B 边界

教程、运营文案、号召类文本需要行动句，这条不适用。绝不用省略号收尾，那是导出截断不是留白。

## cap.kuangye.stance 语气与第二人称直指

### R 原文

```
人生的一生：穷在犟和杠，福在让和躲，富在谋和思，毁在怒和狂。
```
`p0015 | 2026/03/09 | 第 5 页 | 完整帖`（含原书冒号，默认开关下改写为句号）

```
跟任何人，都要少说话，少分享。
```
`p0001 | 2026/03/09 | 第 4 页 | 完整帖`

### I 自述

删掉情态词与让步状语，主语写成全称，谓语用「是」「一定」「从来不」「只需」。把「人们」改成「你」，并给「你」配一个正在发生的具体处境。全书含「你」2417 帖占 59.7%，绝对化词合并命中 1371 帖占 33.8%，含不确定性措辞仅 9.9%。感叹号全书 139 次，破折号 0.8%，情绪靠词汇和句式，不靠标点。

### A1 书中案例

`p0012 | 2026/03/09 | 第 5 页` 全称禁令加第二人称，没有限定词，没有让步。

```
永远不要让别人欠你的钱，要学会让别人欠你的情。
```

### A2 未来触发

场景包括稿子读起来软、满是「可能」「我觉得」、像在科普而不是在对一个人说话。语言信号有「语气硬一点」「别那么客气」「直接点」。与 `assert-first` 的区别在于这里改词汇与语气，那里改句子顺序。与 `concrete-anchor` 常配合，处境要具体到可代入。

### E 执行

1. 删除「可能」「也许」「大概」「似乎」「我认为」「某种程度上」。
2. 把第三人称泛称改为「你」，补一个正在发生的具体处境。
3. 一条帖只立一个全称判断，用禁令词或全称量化词，动作落到具体动词。把绝对化词标为断言项，输出时提示人工确认是否需要补限定条件。

输入契约，草稿文本。输出契约，改写后文本加断言项清单。完成标准，无情态词，含第二人称或全称主语，感叹号 0，破折号 0。

### B 边界

合规文本、医疗、投资、法律、新闻禁止绝对化断言。安慰、致谢、客服、需要合作语气的沟通不用冷感笃定语气，会读成指责。保留用户原有的严谨限定，不为了力度删掉必要的条件。

## 与相邻能力的链接（阶段 3）

| 能力 | also_read | 区分要点 |
| --- | --- | --- |
| single-sentence | assert-first, closing | 只允许 1 句 |
| assert-first | concrete-anchor, question-hook | 判断在前，补证恰好 1 层 |
| mirror-pair | numbered-list, stance | 恰好 2 项，不编号 |
| question-hook | assert-first, concrete-anchor | 首句问句，第二句自答 |
| numbered-list | mirror-pair, concrete-anchor | 项数 3 至 5，先报总数 |
| concrete-anchor | assert-first, stance | 提供证据形态，不定顺序 |
| closing | single-sentence | 只处理末句 |
| stance | assert-first, mirror-pair | 改词汇与语气，不改结构 |
